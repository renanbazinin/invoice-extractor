# מחלץ חשבוניות

**[English](README.md)**

מחלץ חשבוניות קורא חשבוניות שמעולם לא ראה, בעברית ובאנגלית. הוא מחזיר את השדות שלהן: מספר המסמך, תאריכים, סכומים, מע״מ, פרטי הספק והלקוח, ושורות הפריטים.

- אין צורך בתבנית לכל ספק.
- אין שימוש במודל שפה (LLM) או בשירות בינה מלאכותית כלשהו.
- הכול רץ מקומית, בדפדפן או ב־Node.

לכל ערך מצורפות המילים בדף שממנו הוא נקרא. כל שדה מסומן באחד משלושה מצבים:

| מצב | משמעות |
| --- | --- |
| ✔ **מאומת** | נמצא במסמך ואושר באופן בלתי תלוי: חשבון, ספרת ביקורת או תווית חד־משמעית |
| ? **מוצע** | נמצא וסביר, אבל שום דבר בלתי תלוי לא מאשר אותו |
| ! **דורש בדיקה** | קריאות סותרות, בדיקה שנכשלה או קריאה חלשה |

העיקרון המנחה: ערך *מאומת* לא אמור להיות שגוי לעולם. כשיש ספק, המחלץ מסמן את הערך לבדיקה ולא מנחש.

## איך זה עובד

ארבע שכבות, כולן קוד TypeScript דטרמיניסטי:

1. **קריאה:** מילים ושורות עם המיקום שלהן, בסדר קריאה נכון, כולל טקסט מימין לשמאל וטקסט מעורב עברית ואנגלית. ב־PDF דיגיטלי הטקסט נקרא בעזרת pdf.js, ובסריקות ובתמונות בעזרת OCR (tesseract).
2. **מבנה:** זוגות של תווית וערך, וטבלאות, לפי פריסת הדף.
3. **פירוש:** מועמדים לכל שדה סטנדרטי. הם נמצאים בעזרת מילוני תוויות רב־לשוניים ומפענחי פורמטים: תאריכים, סכומים, ח.פ, ע.מ ות.ז, IBAN וטלפונים.
4. **אימות:** בחירת הערכים שמתיישבים זה עם זה (סכום לפני מע״מ ועוד מע״מ שווה לסה״כ, סכום השורות, ספרות ביקורת) וקביעת המצב של כל שדה.

התוצאה כוללת שלושה חלקים:

- **המסמך כפי שנקרא:** כל מילה והמיקום שלה.
- **השדות הסטנדרטיים:** כולל שורות הפריטים.
- **כל שאר הערכים המתויגים שנמצאו:** שדות שאינם ברשימה הסטנדרטית.

התכנון המלא מתואר ב־[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (באנגלית).

## התקנה

צריך [Node.js](https://nodejs.org) בגרסה 22.12 ומעלה. בתיקייה הראשית של הפרויקט מריצים:

</div>

```bash
npm install
```

<div dir="rtl">

### אפליקציית הדפדפן

האפליקציה רצה כולה בדפדפן. הקבצים לא עולים לשום שרת, וה־OCR רץ על המחשב שלכם.

</div>

```bash
npm run web:dev
```

<div dir="rtl">

אחר כך פותחים את http://localhost:5173, גוררים חשבוניות לחלון או מנסים את אחת מחשבוניות ההדגמה.

כדי לבנות גרסה להפצה:

</div>

```bash
npm run web:build
```

<div dir="rtl">

התוצאה נוצרת בתיקייה `web/dist`, בגודל של כ־23MB, רובם מנוע ה־OCR ונתוני השפה.

- **שרת:** זה אתר סטטי. אפשר להעתיק אותו לכל שרת אינטרנט: nginx, IIS, S3, Netlify, GitHub Pages או שרת קבצים פנימי. לא צריך קוד בצד השרת ולא מסד נתונים.
- **לא לפתוח מהדיסק:** חייבים להגיש את האתר ב־http או ב־https. אם פותחים את `index.html` ישירות מהדיסק, הדף נשאר ריק.
- **לבדיקה לפני פריסה:**

</div>

```bash
npm run web:preview
```

<div dir="rtl">

הוראות מלאות, כולל הגדרות שרת ופתרון בעיות, נמצאות ב־[INSTALL.md](INSTALL.md) (באנגלית).

### שימוש באפליקציה

1. גוררים קבצים לחלון או לוחצים על **Add files**. הפורמטים הנתמכים: PDF, PNG, JPEG, TIFF, WebP וטקסט. אפשר כמה קבצים בבת אחת.
2. **מעבר עם העכבר מעל שדה** מסמן במסמך איפה הוא מודפס: הערך בכחול והתווית שלו בכתום. **לחיצה על מילה במסמך** קופצת לשדה או לשורת הפריט שמשתמשים בה.
3. הלשוניות:

   | לשונית | מה מוצג בה |
   | --- | --- |
   | Fields | השדות הסטנדרטיים |
   | Line items | שורות הפריטים |
   | Other fields | שאר הערכים המתויגים |
   | Checks | בדיקות החשבון וההערות |
   | Text | הטקסט המלא בסדר קריאה |
   | JSON | התוצאה המלאה |

4. **ייצוא:**
   - **Export CSV** שומר שורה אחת לכל מסמך, עם כל השדות והמצב שלהם. הקובץ נפתח באקסל כולל עברית.
   - **Download JSON** שומר את התוצאה המלאה של מסמך אחד.
5. **OCR:** במצב Auto, שהוא ברירת המחדל, ה־OCR רץ רק על עמודים בלי שכבת טקסט שמישה.
6. **סיסמה:** קובץ PDF מוגן בסיסמה יבקש אותה. הסיסמה משמשת רק בתוך הדפדפן.

## פרטיות

- **המסמכים לא יוצאים מהדפדפן.** האפליקציה מורידה רק את הקבצים של עצמה: הקוד, pdf.js, מנוע ה־OCR ונתוני השפה. כולם מוגשים מאותו מקום שבו האפליקציה נמצאת, ושום דבר לא נטען מ־CDN חיצוני.
- **שום מסמך לא נשמר.** סגירת הלשונית או רענון שלה מוחקים את המסמכים והתוצאות. הדפדפן כן שומר במטמון את נתוני השפה של ה־OCR, אבל לא את תוכן המסמכים.

## מצב הפרויקט

הפרויקט בשלב מוקדם.

- **התוצאות שנמדדו:** על קבוצות הבדיקה של הפיתוח לא נמצא אף ערך מאומת שגוי. הדיוק הכולל הוא כ־84% על חשבוניות שנכתבו ידנית וכ־97% על חשבוניות שנוצרו אוטומטית.
- **פריסות לא מוכרות מקבלות ציון נמוך יותר.** החולשות העיקריות הן שורות פריטים, מספרי מסמכים, שמות וסריקות באיכות נמוכה.

## נתוני הבדיקה

חשבוניות הבדיקה ששימשו לפיתוח ולמדידה **לא מפורסמות** במאגר. הן נראות כמו חשבוניות אמיתיות, עם שמות, מספרי זהות ופרטי בנק, ואפשר לטעות ולחשוב שאלה נתונים של אנשים אמיתיים. גם המחולל שיוצר אותן לא מפורסם.

בדיקות היחידה משתמשות בקטעים קצרים ובדויים. כלי ההערכה (`eval/run.ts` ו־`eval/score.ts`) כלולים, כך שאפשר למדוד את המחלץ על חשבוניות שלכם:

1. כותבים ליד כל חשבונית קובץ `*.truth.json` עם הערכים הצפויים. המבנה מוגדר ב־`GroundTruth` בקובץ `src/model/types.ts`.
2. מריצים:

</div>

```bash
npm run eval -- your-folder
```
